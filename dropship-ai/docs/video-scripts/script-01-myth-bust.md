# Video Script #1: Myth Bust
**Format:** Talking head + product demo | **Length:** 30-45 sec | **Difficulty:** Easy

---

## HOOK (0-3 seconds)

**Say:** "Everyone keeps saying red light therapy is a scam. So I looked up the actual research."

**Say:** "This isn't some random wellness fad. There are over 5,000 peer-reviewed studies on photobiomodulation. That's the actual scientific name for this."

## CLOSE (25-35 seconds)

**[Text overlay]:** "5,000+ peer-reviewed studies"

**Say:** "I'll break down what to actually look for in my next video."
